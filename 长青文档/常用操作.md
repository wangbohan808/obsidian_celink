### SSH生成密钥

```bash
ssh-keyden -t ed25519 -C "wangbohan808@163.com"
```

- 查看生成的公钥
```bash
wbh@wangbohandeMacBook-Air ~ % cat /Users/wbh/.ssh/Mac_wangbohan808.pub 

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJbk0UmuxZyH/RLFQUVhxgzl4SB2xhiUsi9RyeJUWFWS wangbohan808@163.com
```

- 生成公钥/私钥如果修改了名称需要添加一个新的配置文件
```bash
nano ~/.ssh/config

Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/Mac_wangbohan808
  IdentitiesOnly yes
```


- 查看文件权限
```bash

```


- 多人维护同一个分支，首先做的是需要拉取，并且使用`rebase`
