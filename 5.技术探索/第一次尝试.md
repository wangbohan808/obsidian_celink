###### 关于Linux的一点思考

1. 似乎摄像头项目有一套标准的业务流程？只是简单的替换文件？

```text
【应用层】                【ioctl 指令】               【传入结构体】               【内核/摄像头驱动】
   │
   │  open("/dev/video0")
   ├───────────────────────────────────────────────────────────────────────────────▶
   │                                                                               拿到设备 fd（操作凭证）
   │
   │  VIDIOC_QUERYCAP
   ├────────────────────────────────────▶ struct v4l2_capability
   │                                                                               校验设备、获取摄像头信息
   │
   │  VIDIOC_S_FMT
   ├────────────────────────────────────▶ struct v4l2_format
   │                                                                               设置：分辨率 / YUYV格式 / 逐行模式
   │
   │  VIDIOC_S_PARM
   ├────────────────────────────────────▶ struct v4l2_streamparm
   │                                                                               配置 FPS 帧率
   │
   │  VIDIOC_REQBUFS
   ├────────────────────────────────────▶ struct v4l2_requestbuffers
   │                                                                               【申请】4 块内核环形缓冲区
   │
   │  循环 for(i=0; i<buffer_count)
   │  ├──VIDIOC_QUERYBUF
   │  └──────────────────────────────────▶ struct v4l2_buffer
   │                                                                               【查询】每块内核缓冲区：size / 偏移offset
   │
   │  mmap() 内存映射
   ├───────────────────────────────────────────────────────────────────────────────▶
   │                                                                               内核缓冲区 ➜ 映射到应用虚拟地址（buffers[]指针）
   │
   │  循环入队所有缓冲
   │  ├──VIDIOC_QBUF
   │  └──────────────────────────────────▶ struct v4l2_buffer
   │                                                                               空闲缓冲区入队，等待摄像头写入画面
   │
   │  VIDIOC_STREAMON
   ├────────────────────────────────────▶ enum v4l2_buf_type
   │                                                                               开启摄像头数据流，硬件开始持续写帧
   │
   │———————————— 正式循环采集帧 ————————————
   │
   │  VIDIOC_DQBUF
   ├────────────────────────────────────▶ struct v4l2_buffer
   │                                                                               【出队】取出一帧填满数据的缓冲
   │
   │  直接访问 mmap 映射的 buffers[] 指针
   │                                                                               读取 YUYV 原始图像数据
   │
   │  VIDIOC_QBUF
   ├────────────────────────────────────▶ struct v4l2_buffer
   │                                                                               用完的缓冲重新入队，循环复用
   │
   │———————————— 采集结束 ————————————
   │
   │  VIDIOC_STREAMOFF
   ├────────────────────────────────────▶ enum v4l2_buf_type
   │                                                                               关闭摄像头数据流
   │
   │  munmap 解除映射 / close(fd) / 销毁锁
   ▼
  结束
```
