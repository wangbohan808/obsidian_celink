## startup_cw32l010.s

```assembly
Stack_Size    EQU    0x00000200
```
- 宏定义一个变量，作为栈的大小，512个字节

```assembly
	AREA    STACK,NOINIT,READWRITE,ALIGN=3
```
- 内存每个字节的物理地址由硬件固定，相当于有具体的编号，软件无法修改。
- 8 字节对齐，是要求**数据 / 段的起始地址必须为 8 的整数倍**。ARM 架构下硬件以 8 字节为整块读写单元，对齐后数据完整落在单个读写块内，无需多次读取与数据拼接，既提升读写效率；
- 同时这也是架构硬性规范，非对齐访问可能触发硬件异常、造成数据错误

- 段名不会有太大影响，但是段的属性决定了实际段的归属：
- 带 `READWRITE` → 放进 RAM，设为可读写数据段

- 只要是数据划分地址，在链接表中就会储存
- NOINIT代表上电之后数据初始化为0；如果进行初始化，就直接加载对应数据

2. 每个格子 4 字节，存一个地址
3. 前 16 个格子 = ARM 内核规定（全世界通用）
4. 后面 32 个格子 = 你的芯片厂商规定（外设中断）

6. 中断触发时 → CPU 直接去对应格子取地址 → 跳转执行

```assembly
Reset_Handler   PROC
                EXPORT  Reset_Handler             [WEAK]
                IMPORT  SystemInit
                IMPORT  __main
                    
                LDR     R1, =0x0
                LDR     R0, [R1]
                MOV     SP, R0
               
                LDR     R0, =SystemInit
                BLX     R0
                LDR     R0, =__main
                BX      R0
                ENDP
```
- `Reset_Handler`定义函数名；`PROC`定义函数的开始；`ENDP`定义函数的结束
- `EXPORT  Reset_Handler             [WEAK]`，对外声明，使得外部中断发生时可以找到函数地址，并且允许外部重写函数
- `IMPORT  SystemInit IMPORT  __ main`  ，导入外部函数，使得后续可以进行调用以及跳转

- 三步寄存器联合操作，使得栈指针指向 Flash地址 0x00000000指向的内容，根据向量表定义就是栈顶地址

- `LDR`加载`SystemInit`函数地址，`BLX`跳转执行后返回来；
- `LDR`加载`__ main`函数地址，`BX`跳转执行后不再返回`Reset_Handler`函数
