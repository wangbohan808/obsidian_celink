## Project.sct

```sct
LR_IROM1 0x00000000 0x00001000  {    ; load region size_region
  ER_IROM1 0x00000000 0x00001000  {  ; load address = execution address
   *.o (RESET, +First)
   *(InRoot$$Sections)
   .ANY (+RO)
   .ANY (+XO)
  }
  RW_IRAM1 0x20000000 0x00001000  {  ; RW data
   .ANY (+RW +ZI)
  }
}
```

- LR_IROM：本程序的加载区
- 起始到结束地址：`0x00000000 0x00001000`，总共4KB

- ER_IROM：本程序的代码执行区，在代码加载区就地执行
- 只不过规定了各种文件的执行位置



- 上述这个程序只是在编译器以及链接器处理完毕（将所有的程序完成分类）之后进行装箱（放到指定硬件区域）

## staartup_cw32l010.s

```assembly
Stack_Size    EQU    0x00000200
```
- 宏定义一个变量，作为栈的大小，512个字节

```assembly
	AREA    STACK,NOINIT,READWRITE,ALIGN=3
```
- 内存每个字节的物理地址由硬件固定，软件无法修改。8 字节对齐，是要求数据 / 段的起始地址必须为 8 的整数倍。ARM 架构下硬件以 8 字节为整块读写单元，对齐后数据完整落在单个读写块内，无需多次读取与数据拼接，既提升读写效率；同时这也是架构硬性规范，非对齐访问可能触发硬件异常、造成数据错误
- 段名不会有太大影响，但是段的属性决定了实际段的归属：
- 带 `READWRITE` → 放进 RAM，设为可读写数据段
